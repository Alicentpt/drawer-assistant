# Джессика на ec2-claw

Перенос выполнен 16.10.2026. Управление из PowerShell через существующий SSH alias.

## Проверить и перезапустить

```powershell
ssh ec2-claw 'cd /home/ubuntu/drawer-assistant && sudo docker compose -f deployment/compose.yaml ps'
ssh ec2-claw 'cd /home/ubuntu/drawer-assistant && sudo docker compose -f deployment/compose.yaml restart hermes'
```

Compose запускает контейнер автоматически после перезагрузки EC2.
Локальный gateway ноутбука остановлен: его Telegram-токен очищен, Windows Startup
отключён. `drawer-setup` на ноутбуке заново включит токен из проектного `.env` —
после переезда на ноутбуке эту команду не запускать для рабочего профиля.

## Где данные

- Код и Compose: `/home/ubuntu/drawer-assistant`.
- Постоянный volume: `deployment/state/hermes` внутри этой папки.
- Профиль: `profiles/drawer-assistant` внутри volume; в контейнере это
  `/opt/data/profiles/drawer-assistant`.
- Персона, память, история, навыки и файлы изображений находятся в профиле.
- Заказы и бинарные референсы: RDS PostgreSQL 17, база `drawer`, роль
  `drawer_assistant`. Runtime не использует администратора `postgres`.
- URL с паролем хранится в `.env` профиля, TLS — `verify-full` с CA AWS.
  IAM-токены для постоянной работы не требуются.

В окончательном снимке перенесены 27 сессий, 1091 сообщение и 81 файл результатов
генераций/коллажей. Прикладная база: 5 заказов, 4 референса, 79 заданий и 3 batch.
Все девять таблиц сверены по содержимому, включая байты референсов. Windows-пути
к сохранённым результатам заменены Linux-путями только в копии для переноса.

Модель по умолчанию — `tencent/hy4-preview`. Бот отвечает только прежней группе,
по обращению; история участников общая, личка отключена. Проверка напоминаний —
раз в 30 минут; сводка — 12:00 PM МСК. Часовой пояс — `Europe/Moscow`.

## Генерация

EC2 подключён к Tailscale как `ec2-jessica`; контейнер использует DNS Tailscale
и исходящие маршруты хоста. Docker bridge отделяет его порты от другого Hermes,
который уже работает на сервере. Порты контейнера в интернет не публикуются.

Адрес Anima — `https://rasist-bro.tailbaf981.ts.net`. Если он отвечает HTTP 502,
проверить запущенный ComfyUI на ПК художницы и порт назначения Tailscale Serve.
Доступность ПК в Tailscale сама по себе не означает, что ComfyUI включён.

## Копии для отката

Приватная копия на ноутбуке — `.local/ec2-cutover-20261016` в репозитории:
окончательный архив профиля, исходный SQLite и конфигурация локального запуска.
Серверная копия — `/home/ubuntu/.local/state/drawer-cutover-20261016`.

Откат сначала останавливает контейнер. После новых записей в RDS старый SQLite
неактуален: сначала согласовать данные. Не запускать два экземпляра одного бота.
Другой Hermes на EC2 управляется отдельно и не входит в этот Compose.

## Предупреждение PM при запуске CLI

Hermes может писать `venv: out of sync with uv.lock`: его проверка включает
декларацию зависимостей нашего directory plugin, а пакеты добавлены отдельным
слоем образа. Отдельно проверено: базовое окружение соответствует lock, а драйвер
PostgreSQL доступен в изолированном Python и дочерних процессах инструментов.
Сквозной вызов сводки самой моделью прошёл. Предупреждение не скрывается.
Обновлять эту установку следует пересборкой образа, сохраняя volume.
