1. Закройте ComfyUI.
2. Распакуйте ВЕСЬ архив в отдельную папку.
3. Для полной установки дважды нажмите install-anima-controls.cmd.
   Если нужны только Python-пакеты — repair-anima-python.cmd.
4. Если появится выбор папки, выберите папку вашей установки ComfyUI,
   внутри которой находятся custom_nodes и .venv.
5. После успешной установки снова откройте ComfyUI.

Не нужно активировать окружение, устанавливать системный Python,
запускать от администратора или менять глобальную политику PowerShell.
Git нужен для полной установки; для восстановления Python-пакетов не требуется.
Скрипт показывает выбранный Python и сохраняет install-*.log рядом с собой.
Если произошла ошибка, передайте этот лог. При ошибке окно остаётся открытым.

Прежний источник Character недоступен (HTTP 401). Для Character нужна уже
скачанная разрешённая копия; без неё полная установка не объявляет его готовым.
