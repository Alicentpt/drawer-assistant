# Архитектура и этапы

```text
Telegram → Hermes → Python-плагин
                    ├─ заказы + дедлайны → SQLite ← cron без LLM → Telegram
                    ├─ ссылки-референсы → SQLite
                    └─ генерация → Hermes Codex OAuth / ComfyUI HTTP
```

Ядро содержит заказы, задания и выбор провайдера; адаптеры — Hermes, SQLite, HTTP.
Маленький Python-пакет позволяет добавить MCP позже, если он понадобится.
Hermes переиспользуем для диалога, Telegram и OAuth. Картинки храним файлами,
метаданные — в SQLite. Данные лежат вне репозитория, в `DRAWER_DATA_DIR`
и профиле Hermes `drawer-assistant`; версия кода обновляется отдельно от данных.

## 0. Окружение

Windows, Python из Hermes, uv, правила, Google docstrings, статические проверки,
pre-commit, CI, `.env.example`. Вся разработка в ветках с PR.
Hermes на этом ноутбуке при подготовке: commit
`68420e1912a43949d4973df0ecf3c423b4370345`, Python 3.14.7.
Это запись установленной ревизии; перед интеграцией фиксируем проверенную версию.

## 1. Два инструмента

Реализовано для первого теста: персона Джесс, native plugin `drawer`, заказы,
перенос/закрытие сроков, привязанные ссылки, cron без LLM и очередь ComfyUI.
Инструменты зарегистрированы отдельно: orders, references, generate.
Таймер вызывает `.venv` проекта; SQLite сериализует отправку и изменение заказа.
HTTP-запросы ограничены 30 секундами, статус GPU-задания хранится между вызовами.

- Дедлайны: создать, перенести, завершить, показать; часовой пояс, SQLite,
  напоминания без LLM, журнал отправок, повтор после сбоев.
- Референсы: текст/исходник → задание → картинки. Облако — штатный image tool
  Hermes; ComfyUI — HTTP-клиент к GPU-серверу. Для тестов без сервера — HTTP-мок.
- Первые живые проверки: ChatGPT OAuth, одна генерация и одна правка.
- Уже проверены: OAuth-диалог, вызов orders из Hermes, генерация PNG новым
  ComfyUI-клиентом на L40. Облачная картинка/правка и GPU на 3080 ещё не проверены.
- Приёмка: сохранность заказа после рестарта, отмена старого напоминания при
  переносе, получение картинки в Telegram, корректные таймауты/ошибки провайдера.
- Спящий ноутбук не отправляет напоминания; при запуске обрабатываем пропущенные.

## 2. База художницы и правки

Материалы и переписки при заказах, вариации и маски, продолжение заданий после
перезапуска. Проверенные GPU-workflow, версии custom nodes и манифест моделей.
GPU-сервер для испытаний предоставляет пользователь.

## 3. Тренды и передача

Выбранные площадки, примеры с источниками и датами, идеи адоптов/YCH.
Лайки, объявленная цена и подтверждённая продажа — разные признаки.
Далее: установка, обновления, миграции, резервные копии и постоянный worker.
