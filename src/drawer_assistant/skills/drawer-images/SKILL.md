# Генерация и коллажи

Только Nova Anime AM v2.0 через MCP drawer_generation. Найди инструменты через
tool_search: Hermes добавляет префикс MCP. Старые drawer_anima,
drawer_anima_batch и drawer_image_sheet заменены MCP. Не меняй провайдера при сбое.
Сначала прочитай drawer-anima; для референсов — drawer-anima-controls.
Заказ и клиентка для генерации не обязательны.

## Инструменты

- anima_generate — один кадр по тексту.
- anima_style / anima_depth — один тип контроля по изображению.
- anima_batch — несколько отдельных кадров и необязательный коллаж.
- generation_status — статус одиночного задания или пачки.
- image_sheet — сборка уже готовых картинок, без новой генерации.
- generation_health — доступность GPU-only, нод, весов и sampler по режимам.

references — абсолютные файлы на EC2. Для референса из заказа сначала
drawer_references get; для Telegram используй каждый путь вложения альбома.
MCP загружает файлы в ComfyUI сам. Windows-путь художницы и URL не подходят.

## Batch

Один mode на пачку: text/style/depth. frames — 2–16 объектов,
каждый с отдельным prompt. defaults задаёт общие options, references — общие refs.
Каждый frame может независимо переопределить options и references:
seed, cfg, steps, размеры, sampler, strength, start/end_percent и prompt preset.
Параметры сливаются по ключам, ссылки кадра полностью заменяют общие.

Для сравнения силы Style: общий seed/сюжет/ref и три frame с
options.strength 0.5 / 0.65 / 0.85. Меняй один параметр за сравнение.
Для разных идей — полноценный сюжет каждого кадра. Не проси одну генерацию
рисовать сетку. columns задаёт колонки; labels — по одной подписи на кадр.
assemble=false оставляет отдельные кадры. GPU jobs запускаются последовательно.

## Статус и отправка

request_id устойчивый: тот же id/запрос не дублирует генерацию; другой запрос
с тем же id отклоняется. Проверь поле delivery в результате запуска.

**delivery.automatic=true:** worker на EC2 сам проверяет ComfyUI, продолжает все
кадры batch и передаёт результат в штатную очередь доставки Hermes. Отправка
идёт в исходный разрешённый чат без нового сообщения пользователя.
Скажи один раз: «Приняла, результат пришлю сюда автоматически». Не проси
написать «проверь», не крути status и не отправляй те же MEDIA самостоятельно.
При явном запросе статуса generation_status читает сохранённый прогресс.
Перезапуск worker/gateway не создаёт повторную генерацию.

**delivery.automatic=false:** локальный вызов или старое задание без маршрута.
Автодоставку не обещай. generation_status проверяет результат и продолжает batch;
один вызов ждёт до 25 секунд. После трёх проверок без прогресса сообщи pending.
Готовые MEDIA отправляй дословно отдельными строками.

submitting/needs_attention — неопределённость: не запускай дубль. Worker сообщает
об ошибке исполнения или необходимости проверки. delivery.state=unknown/failed
означает проблему отправки: не повторяй её без явного запроса пользователя.
Проверка соединения сама повторяется при временном обрыве, генерация — нет.

Для Depth worker отправляет также точную карту и окно применения. Показывает
время каждого кадра и отдельно сборки; это серверное выполнение без очереди
и передачи. Полные промпты и параметры — по запросу. В generation_health
worker_running показывает недавний heartbeat, automatic_delivery — настройку.

Сбой не уничтожает готовые кадры. Неполный лист не выдавай за полный.
Частичный можно собрать image_sheet по просьбе. Новый запуск после подтверждённой
ошибки — новый id и явное намерение повторить, не автоматическая петля.

image_sheet принимает files по порядку, columns, labels, cell_size и gap.
Оригиналы не меняются; сборка вписывает без обрезки. Подписи рисует ImageMagick,
не Anima; в labels не используй %, @ и переводы строк.
При missing dependencies сообщи проблему; не администрируй сервер из Telegram.
