# Генерация через Anima

- Единственная модель — Nova Anime AM v2.0: `drawer_anima` для одного кадра,
  `drawer_anima_batch` для нескольких. Старые Z-Image,
  Flux, Alibaba/Qwen и ChatGPT OAuth инструменты отключены. Не вызывай их
  по прежней истории или инструкции; не заменяй Anima при ошибке.
- Сначала читай `drawer-anima`. Передавай текст сцены; код сам добавляет
  согласованные quality/scenery prefix и negative. Не дублируй пресет.
- Вызови start с устойчивым id; затем status с тем же id. Если задача уже принята,
  проверяй её, не создавай новую из-за очереди. После неясного submitting не повторяй
  отправку. При ошибке не обещай готовую картинку и не запускай другую модель.
- status ждёт до 25 секунд, опрашивая ComfyUI с паузой 5 секунд. Не более трёх
  вызовов status на один кадр за ответ; если он ещё в очереди/работает, сообщи
  pending один раз и остановись. Не обходи защиту от зацикливания новым id.
- Этот инструмент принимает только текст. Сохранённая картинка-референс остаётся
  в базе; не обещай перенос её стиля или прикрепление к генератору, пока такого
  входа нет в схеме.
- Промпт сохраняет сюжет, позы и настроение запроса. Готовый пользовательский
  промпт не переписывай самовольно; для придумывания идей используй его бриф.
- Когда status вернул media, вставь MEDIA: строку дословно отдельно от подписи.
  Укажи модель и generation_seconds: это серверное выполнение, без очереди
  и передачи. Если время пустое, напиши «время не измерено».
- Оформляй результат по drawer-readable-messages: короткий итог, модель и время.
  Полный промпт и технические поля показывай по запросу.
- Для ожидания достаточно одного сообщения о статусе. Не отправляй цепочку
  «жду / в очереди / ещё жду». Автоматическая доставка результата не настроена:
  не обещай её после завершения ответа. Скажи, что проверка возможна по запросу.

## Несколько кадров и сборка изображений

Генерация и сборка — общие операции, не требуют заказа или клиентского брифа.
Для одного изображения используй drawer_anima; для готовых файлов генерация не нужна.

1. Для нескольких новых изображений/вариантов/панелей используй drawer_anima_batch.
   Для 4×4 подготовь 16 отдельных промптов и columns=4; для 3×1 — три и columns=3.
   Каждый промпт описывает один кадр, не сетку. Общий стиль/внешность повторяй
   в каждом промпте; задавай отдельный ракурс или действие для каждой вариации.
2. Вызови start с одним устойчивым id пачки, prompts (массив строк), columns.
   Необязательные labels — по одной подписи на кадр; cell_size/gap задают сборку.
   Код сохраняет весь план и создаёт отдельные GPU jobs, затем проверяет прогресс.
3. Вызывай status только с action/id этой пачки. Он ждёт до 25 секунд с паузами.
   Пока completed_images увеличивается, продолжай проверять. После трёх проверок
   без прогресса остановись и сообщи pending. Не меняй id и не запускай дубль.
   needs_attention означает сбой/неопределённую отправку/неотправленные кадры:
   сообщи фактические состояния, не повторяй отправку автоматически.
4. Сборка выполняется автоматически только когда все кадры готовы; используй
   финальный MEDIA. Проверь expected_images/completed_images: одна генерация
   с нарисованной сеткой не является набором независимых попыток.
5. Если картинки уже готовы, используй drawer_image_sheet без новой генерации:
   files — массив фактических локальных путей в нужном порядке, columns — колонки,
   labels — подписи, cell_size — ячейка, gap — поля. URL и удалённые пути не подходят.
   Для сохранённых картинок получи локальные файлы через drawer_references get.
6. Кратко укажи число кадров и времена из frames[].generation_seconds;
   assembly_seconds — отдельно. Не называй сумму серверных времён полным временем
   ожидания: очередь и передача в них не входят.

Сборка сохраняет исходники и создаёт новый PNG в image-sheets. Масштабирование
вписывает картинку без обрезки, не добавляет деталей. Доступно 1–16 изображений,
1–8 колонок, cell_size 128–1024, gap 0–64; PNG/JPEG/WebP до 20 MiB на файл.
Не создавай дополнительные варианты, если пользователь просил только сборку.

Если один кадр не удался, сохрани удачные и сообщи об ошибке; не выдавай неполный
лист за полный. Частичный лист собирай по просьбе пользователя. Повторная сборка
не запускает Anima. При недоступном ImageMagick сообщи об ошибке установки;
не подменяй сборку генерацией коллажа и не администрируй пакеты из Telegram.
