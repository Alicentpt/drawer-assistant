# Референсы Nova

Сначала drawer-anima и drawer-images. All In One и Pose tool не подключены.
Один mode на генерацию/пачку. Каждый референс СНАЧАЛА растягивается/сжимается
ImageScale до разрешения генерации: по умолчанию 512×512, crop=disabled,
без паддинга/рамок/исключений. Это может исказить пропорции исходника.

## Style — anima_style

Один reference. strength=0.65 по умолчанию. Ниже может слабо переноситься стиль;
ближе к 1 и выше часто переносится также композиция исходной сцены.
Это рабочие ориентиры пользователя, не гарантия для любого референса.
В prompt очень желательно описать стиль английскими тегами и фразами:
манера, мазки, фактура, края, палитра и свет. Сравнивай при одинаковом seed.
ref_image_size=512, siglip_layer=-1, gray_null=false, use_lora=true.
ip_cfg_separate=false: влияние связано с общим CFG; ip_cfg_scale следует cfg.
Не обещай чистого отделения манеры от содержания/внешности картинки.

## Depth — anima_depth

Один reference композиции. Depth задаёт объём, расположение объектов и может
направлять позы по силуэту тела. Это не точный скелет, пальцы/суставы не фиксирует.
Не бери глубину из стилевого образца, если он не выбран как композиция.

DepthAnything V2 Small строит карту из уже скейленного изображения.
Именно вход ControlNet сохраняется как depth_preview/depth_media. Покажи карту
вместе с результатом; не подменяй её исходной цветной картинкой.

- strength=1.0; обычно оставляй такой.
- start_percent=0.0 — влияние с начала шумоподавления.
- end_percent=0.6 — влияние отключается после первых 60% процесса;
  оставшиеся шаги свободнее уточняют детали.
- 0 <= start_percent < end_percent <= 1.

Это доля ПРОЦЕССА генерации, а не фильтр яркости/шума/глубины карты.
Более раннее отключение может ослабить перенос шумных деталей в результат,
но пиксели предпросмотра от start/end не меняются. depth_window возвращает
фактическое окно. Поздний start ослабляет ранний контроль композиции;
end ближе к 1 дольше навязывает детали. Меняй один параметр за сравнение.

При missing nodes/models — generation_health. Не меняй режим/endpoint/модель
молча и не устанавливай ноды из Telegram.
