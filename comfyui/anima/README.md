# Nova Anime AM v2.0: текст и img2img

[UI workflow](nova-anime-am-v20-text-img2img.ui.json) импортируется в ComfyUI.
[API workflow](nova-anime-am-v20-text-img2img.api.json) — тот же граф для автоматизации.
В Джессике доступен отдельный `drawer_anima` для генерации по тексту: он использует
[компактный API preset](../../src/drawer_assistant/workflows/nova-anime-am-v20.api.json)
без LoadImage, с пользовательским positive prefix и фиксированным negative из
[инструкции Hermes](../../src/drawer_assistant/ANIMA.md). Img2img доступен в UI workflow.

1. Откройте workflow и загрузите картинку в «Заменить на свой референс».
   На настроенном сервере уже есть техническая картинка-заглушка.
   На новом сервере загрузка нужна даже для текста: ComfyUI проверяет LoadImage.
2. Заполните общий промпт и при необходимости негативный.
3. «РЕФЕРЕНС» выключен — text-to-image; включён — img2img.
4. Для img2img регулируйте «Сила перерисовки»: 0,3–0,5 сохраняет больше исходника,
   0,6–0,8 сильнее меняет его. Это ориентиры, а не гарантия результата.

Референс влияет на композицию и цвета. Это **не изолированный перенос стиля**,
не ControlNet и не Anima Native Context. Последнему нужны специальные веса;
замена их на Nova несовместима с тем workflow.

Старт: 512×512, batch 1, Euler ancestral, simple, 25 шагов, CFG 5.
Для текста denoise автоматически равен 1, для img2img по умолчанию 0,6.
При изменении разрешения задайте его и в EmptyLatentImage, и в ImageScale.
ImageScale обрезает референс по центру под выбранные пропорции.

ComfyUI запускается с `--gpu-only`; tiled VAE также работает на GPU.
CPU encoder, low-VRAM fallback и выгрузка моделей в RAM не используются.
Размеры файлов не доказывают соблюдение бюджета 9 ГБ VRAM.

## Проверка на RTX 3080 10 ГБ, 07.10.2026

Обе ветки выполнились и сохранили PNG 512×512. Img2img проверен на синтетической
цветной сетке: проверена работа ветки, а не качество переноса художественного стиля.
Текстовый режим был первым; img2img запускался следом в том же процессе.

| Режим | Полное время запроса, с | Наблюдавшийся пик VRAM, ГБ (10⁹) |
|---|---:|---:|
| Текст | 33,08 | 5,57 |
| Img2img, denoise 0,6 | 18,69 | 5,54 |

Время включает загрузку весов, VAE и задержку опроса API. Разные режимы и состояние
кешей не позволяют по этим двум запускам строго сравнивать скорость.
Пик — `vram_total - vram_free` из `/system_stats`, опрос каждые 0,5 с плюс HTTP
задержка (39 и 21 отсчёт). Он включает остальные выделения GPU, но может пропускать
короткие пики; это не принудительный лимит. Большие разрешения не проверены.
В логах encoder и VAE: `load device: cuda:0, offload device: cuda:0`;
Anima загружена полностью, `--gpu-only` оставлен включённым.

UI JSON сохранён в серверный каталог Workflows как
`Jessica - Nova Anime AM v2 - Text and Reference.json`; чтение обратно совпало
байт в байт. Генерации проверены через API. Визуальная проверка редактора на
ноутбуке не выполнена: Chrome возвращал `ERR_CONNECTION_CLOSED`.

## Модели и совместимость

Встроенные nodes ComfyUI **0.39.0**, frontend **1.53.10**; custom nodes не нужны.
Источники и точные revisions закреплены в [models.json](models.json).
SHA-256 взяты из метаданных Hugging Face; хеш Nova совпадает с карточкой версии.
Это идентификаторы ожидаемых файлов, не отдельная проверка байтов на удалённом диске.

| Файл | Папка внутри models |
|---|---|
| novaAnimeAM_v20.safetensors | diffusion_models |
| qwen_3_06b_base.safetensors | text_encoders |
| qwen_image_vae.safetensors | vae |

Нужен **Qwen3 0.6B Base**, обычный текстовый энкодер Anima.
Qwen 4B abliterated от Z-Image/Klein сюда не подставляем.
В CLIPLoader тип `stable_diffusion` соответствует официальному шаблону Anima;
название loader не означает, что нужно скачать отдельный CLIP.

Источники: [Anima и установка](https://huggingface.co/circlestone-labs/Anima),
[выбранная Nova v2.0](https://civitaiarchive.com/models/2604424?modelVersionId=2994532).
В карточке Nova автор запрещает коммерческое использование неизменённых генераций;
учитывайте это при подготовке комиссионных работ.
