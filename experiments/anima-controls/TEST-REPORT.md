# Anima controls: GPU-тест 12.10.2026

**Технический прогон пройден; точность переноса пока экспериментальная.**
Проверены Style, Pose, Character, Depth и All In One с тремя референсами.
Рабочий endpoint бота через Tailscale не менялся. Эти графы пока не подключены
к Hermes tools: стабильность качества и проверка на целевой карте ещё впереди.

## Условия и замеры

- Временный RunPod, RTX 3090 24 ГиБ. Это не испытание RTX 3080 10 ГБ.
- ComfyUI 0.30.0, torch 2.10.0+cu130, transformers 5.17.0,
  onnxruntime-gpu 1.31.0, rtmlib 0.0.16. Код и веса закреплены в revisions.json.
- Nova Anime AM (точный файл/ревизия зеркала закреплены), Qwen3 0.6B, Qwen Image VAE.
- Финальная серия: 512×640, seed 20261012, er_sde/simple, 30 шагов, CFG 4,
  FP8 e4m3fn storage diffusion, GPU compute. Quality/negative пресеты сохранены.
- Каждый основной замер после перезапуска ComfyUI, до следующего задания.
  Время: execution_start → execution_success из history, включая загрузку моделей
  и препроцессор; без ожидания очереди, передачи картинки и сборки листа.
- Пик: максимальный memory.used всей карты из nvidia-smi, опрос примерно каждые
  0,2 секунды плюс время вызова утилиты. Это выборочный замер, не абсолютный пик
  аллокатора. MiB / 1024 = GiB; на пользовательском ПК расход драйвера будет другим.

| Режим | Серверное время, с | Замеренный пик, MiB | GiB |
|---|---:|---:|---:|
| Без адаптеров | 12,54 | 4092 | 4,00 |
| Стиль | 16,43 | 5726 | 5,59 |
| Поза | 16,11 | 6926 | 6,76 |
| Персонаж | 18,79 | 6076 | 5,93 |
| Все три | 26,10 | 8656 | 8,45 |
| Глубина, отдельный прогон | 16,72 | 4804 | 4,69 |

Depth после исправления проверен отдельно.
В обычной точности на 512×512: поза 10648 MiB, персонаж 9820 MiB,
все три 12504 MiB. Поэтому обычные веса не приняты для бюджета 9 ГиБ.
Старые ошибки и повторные тесты сохранены локально, не выданы за успешные прогоны.

## Что показали изображения

- **Стиль:** меняет свет, цвет и манеру отрисовки, но убедительного переноса
  живописной фактуры первого рисунка нет. Цвет волос из style reference может
  попадать в результат. Это Character Reference adapter, а не изолированный
  проверенный style encoder. Называть точным переносом стиля нельзя.
- **Поза:** скелет из второго рисунка распознан. Наклон головы и общая динамика
  читаются, но руки и расположение тела не повторяются точно.
- **Персонаж:** поддерживает белые волосы/одежду, но лицо и пропорции дрейфуют.
  Одного примера недостаточно для утверждения сохранения идентичности.
- **All In One:** все три ветки исполняются совместно. Признаки смешиваются,
  точные стиль, лицо и поза одновременно не сохранены. Усиление IP до 1.6 с
  независимым IP CFG 7 и усилением character/pose дало пересвет и цветовой сдвиг;
  этот вариант отвергнут, в default не перенесён.
- Negative пресет содержит painting, crayon, graphite, cartoon — это конфликтует
  с задачей живописного переноса. По прежнему требованию пользователя пресет
  не изменялся. В исходной серии отдельного теста negative не было; дополнение ниже его описывает.

## Проверка переключения

После общего задания выполнили All In One: все off, только Style, только
Character, только Pose. У каждого результат **попиксельно совпал** с независимым
baseline/соответствующим standalone (ImageMagick AE = 0). Это проверяет отсутствие
остаточного влияния LoRA при переключении. Остальные комбинации покрыты тестом
зависимостей графа, но все восемь комбинаций на GPU отдельно не прогонялись.

Все три исходных изображения переданы только на предоставленный пользователем
тестовый под. Исходники, результаты и полные history/VRAM samples сохранены в
локальной игнорируемой папке .local/anima-controls-20261012; в Git изображений нет.
На поде исходные байты, API-графы и history находятся в /opt/drawer-tests и
/opt/drawer-comfy/input. UI workflow сохранён на сервере и реально запущен
кнопкой «Запустить»; браузерная вкладка не является единственной копией.

## Следующая проверка

### Дополнение: All In One v2 с Depth

Добавлена четвёртая независимая ветка. Один PrimitiveBoolean одновременно
переключает positive/negative conditioning через два lazy switch. Depth может
работать без Pose, с Pose и вместе с Character/Style. По умолчанию Depth off.
Depth hook исправлен: контроль воздействует на генерируемый кадр, не на чистые
reference frames InContext. Патч закреплён в depth-dtype.patch.

Те же карта, seed, sampler, CFG, steps и метод измерения; чистый процесс
перед каждым основным прогоном. Flow shift 3, включая Depth (отдельный граф
Depth ранее использовал 5, поэтому сравнение с ним не только по наличию ветки).

| Режим | Размер | Серверное время, с | Пик MiB | GiB |
|---|---|---:|---:|---:|
| Depth внутри AIO | 512×640 | 20,64 | 5616 | 5,48 |
| Pose + Depth | 512×640 | 17,57 | 7570 | 7,39 |
| Style + Character + Pose + Depth | 512×640 | 28,98 | 9244 | 9,03 |
| Все четыре, новый размер по умолчанию | 512×512 | 25,69 | 8834 | 8,63 |

Все четыре на 512×640 превышают бюджет 9 GiB, поэтому новый AIO по умолчанию
512×512. Испытание RTX 3080 остаётся необходимым: Windows/драйвер и другие
приложения меняют расход. Более ранние результаты 8,45 GiB — только три ветки.

После совместного Depth-прогона All In One со всеми ветками off попиксельно
совпал с прежним baseline, а три ветки с Depth off — с прежним All In One:
ImageMagick AE=0 в обоих случаях, при 512×640. Остаточного влияния Depth нет,
но GPU-кеш может сохранять загруженные веса: в тёплой серии peak достигал
9276 MiB даже после OFF. OFF не означает немедленного освобождения памяти.

Все 16 комбинаций покрыты проверкой зависимостей; все 16 на GPU не перебирались.
Новый UI реально запущен кнопкой при Depth=true, Pose=true и остальных true;
history 62e2d537-e0fb-4b1b-965d-6fecb77d3dc2 завершён success.
Референсы прежние. По изображениям добавление Depth лучше удерживает общий
ракурс/силуэт, но точное лицо и живописная фактура всё ещё не воспроизведены.
Новые графы и результаты сохранены в прежней локальной .local папке.
Ручная настройка — TUNING.md; диапазоны совместных сил — экспериментальные.

- 0.8: появляются зеркало и похожая сцена, манера остаётся гладкой.
