# Anima: проверка переноса стиля и персонажа

12.10.2026. 56 завершённых GPU-заданий, из них 43 с FP8-весами diffusion.
После уточнения пользователя новые сравнения точности весов не проводились.
13 ранних заданий с BF16 сохранены только как история диагностики.
Рабочая модель художницы, endpoint Tailscale и пресет бота не изменены.

## Результат

- IP-Adapter влияет на изображение, но переносит содержание вместе с манерой.
  Увеличение strength не превращает Character Reference в чистый style adapter.
- На официальной Anima Base живописная манера заметнее, чем на Nova Anime AM,
  при одинаковых FP8-настройках. Проверили кафе, поезд и зимний лес; в кафе —
  два seed. Это визуальное сравнение на одном референсе стиля, не доказательство
  преимущества Base для любых задач.
- Независимый IP CFG и позднее включение адаптера ослабляют заимствование
  композиции, одновременно ослабляя стиль. Чистого style-only режима не нашли.
- Character InContext технически работает. При strength 1–1.4 внешность
  не сохранилась; второй вход с кропом лица проблему не решил. На Base при 3
  появились светлые волосы и похожая палитра одежды, но точное лицо не получено.
  При 8 голова обрезана. Эти веса не рекомендуются как готовый пресет identity.

Успешное выполнение графа не означает успешный перенос стиля или персонажа.
Инструменты controls остаются экспериментальными.

## Условия

RTX 3090 24 GiB, Linux, ComfyUI 0.30.0, PyTorch 2.10/cu130, GPU-only.
Перед каждым заданием новый процесс; CPU/RAM offload не использовался.
512×640, 30 шагов, er_sde/simple, CFG 4, AuraFlow shift 3,
seed 20261012 и 20261013. Qwen 3 0.6B и Qwen Image VAE одинаковы.
FP8 означает хранение весов diffusion, не всех операций графа.

Positive сохранял согласованный quality/scenery prefix и задавал новую сцену
с одной взрослой женщиной, без описания волос, глаз и узнаваемой внешности.
Тесты стиля не включали Character/Pose/Depth; тесты персонажа — Style/Pose/Depth.
Из negative только для экспериментов удалили cartoon, graphic, painting,
crayon, graphite, abstract. Рабочий negative бота не меняли.

Время: execution_start → execution_success, включая загрузку моделей,
без запуска процесса, очереди и скачиваний. Пик: nvidia-smi всей карты
с выборками через 0.2 с; краткие пики могут быть пропущены. Замера на RTX 3080
Windows нет, бюджет 9 GiB на целевой машине этим не подтверждён.

## Разбор IP-Adapter

В checkpoint 560 ненулевых LoRA-тензоров: 280 пар down/up.
Из них 112 пар cross-attention, 112 self-attention, 56 MLP.
Опубликованный загрузчик использует только 112 cross-attention пар.
Наш прежний изолированный патч сохранял этот выбор.

Отдельно проверили полный набор 280 пар, два seed, независимый CFG и окна
включения. Полный набор меняет картинку, но не решает отделение стиля
от содержания. Без рецепта обучения нельзя объявить пропущенные пары
доказанной ошибкой автора. Полный загрузчик не установлен в рабочий workflow.

`strength` масштабирует image tokens до K/V attention; это не процент стиля.
При `ip_cfg_separate=false` поле `ip_cfg_scale` не задаёт отдельную силу:
влияние связано с текстовым CFG. При `true` коэффициент IP равен
`ip_cfg_scale - 1`. На GPU связанный CFG 4 и отдельный IP CFG 5 дали
попиксельно одинаковый результат: B01/B02, ImageMagick RMSE=0.
Повтор L03/B01 также RMSE=0.

При strength 1.6 и отдельном IP CFG 3 новая сцена лучше удерживается,
но Nova остаётся сравнительно гладкой. Base с теми же параметрами дала
более выраженные живописные пятна в нескольких сценах. Это кандидат
для ручного сравнения, не универсальный default.

Окно включения реализовано только в отдельном исследовательском патче:
оно отключает image tokens, но оставляет LoRA. Полное окно 0–1 совпало
с контролем B06/C01, RMSE=0. Включение с 50–70% прохода ослабило копирование
сцены, одновременно потеряв желаемую манеру.

## Разбор Character InContext

Проверили исходный портрет, один кроп лица и два входа через
AnimaRefLatentBatch. Кроп — часть той же картинки, не независимый ракурс.
LoRA strength_model=1, reference strength 0/1/1.4/3/8, cond_only=true,
ref_timestep=0, окно 0–1. Не все силы перебраны на обеих моделях;
3/8 и нулевой контроль проверены на Base с одним seed.

Временный диагностический узел подтвердил:

- загружены 448 LoRA-патчей;
- референс добавлен отдельным latent-кадром с timestep 0;
- reference latent ненулевой, стандартное отклонение около 0.586;
- attention активен, маска отделяет условную и безусловную ветки CFG;
- диагностика не меняет результат: D02/E01, RMSE=0.

Простого отсутствия референса или незагруженной LoRA не найдено.
Узнаваемость лица остаётся проблемой качества. Маска фона, второй независимый
ракурс и другие персонажи в этой серии не проверены. Теги внешности могут
помочь согласно инструкции автора, но их не добавляли: они скрыли бы слабость
переноса при требовании нейтрального промпта.

## Артефакты и дальнейшее использование

В `.local/anima-deep-20261012` сохранены все 56 исходных результатов,
коллажи, точные positive/negative, графы, history, времена, выборки VRAM,
исходники экспериментальных патчей и локальная HTML-галерея.
Изображения пользователя и полные диагностические логи не коммитятся.
После отмены отправок в Telegram результаты доставляются только в текущий чат.

Временный диагностический узел архивирован вне custom_nodes. На тестовом поде
восстановлен прежний изолированный IP-Adapter, сервер запущен GPU-only,
очередь пуста. Под не выключался, рабочий Tailscale-сервер не менялся.
Следующий кандидат для стиля — ручное сравнение Base/Nova на других референсах;
для Character сначала нужна проверка узнаваемости, а не выпуск готового tool.
